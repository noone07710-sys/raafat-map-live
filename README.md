# شركة رأفت للدعاية والإعلان والتجارة العامة — الموقع العام

هذا المستودع مخصص **لملفات الموقع العامة فقط** ولا يحتوي قاعدة البيانات أو مفاتيح إدارة سرية.

## الموقع
بعد تفعيل GitHub Pages بنمط **GitHub Actions** وتحقق نجاح سير العمل:
https://noone07710-sys.github.io/raafat-map-live/

## النشر
Settings → Pages → Build and deployment → Source: GitHub Actions.

## ملاحظات التشغيل
- `config.js` يحوي مفتاح Supabase من نوع publishable (مفتاح عام مخصص للمتصفح)، وليس secret/service_role.
- البيانات الحساسة والصلاحيات يحميها RLS على Supabase. لا تضع بيانات العقود في جداول العرض العام.
- لا توجد قطع إعلانية وهمية معروضة. ستظهر القطع الحقيقية بعد إدخالها من الأدمن ونشرها.
- لاستخدام إنشاء حساب أدمن لأول مرة، يلزم التحقق من البريد وضبط Supabase Authentication URL Configuration على رابط GitHub Pages.
- تبقى صلاحية إنشاء وتعديل القطع للموظفين المعتمدين فقط؛ أي زائر ليس أدمن لا يستطيع إدارة المواقع.
- مصدر التطوير الخاص محفوظ في مستودع منفصل Private.
